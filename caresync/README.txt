CareSync - Healthcare Appointment & Queue Management (website)
Open index.html in your browser. Login: any email + a password of 6+ characters.
index.html = login | dashboard / patients / doctors / appointments / book / queue / capacity / reports / settings .html
css/style.css = all styling | js/data.js = sample data + helpers | js/app.js = pages | js/login.js = login
Data is saved in the browser (localStorage). Settings > Reset demo data restores the sample data.
